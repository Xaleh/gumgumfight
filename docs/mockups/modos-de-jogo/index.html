Selado: de onde vêm as cartas e como montar

Uma porta só para todos os modos limitados. Primeiro a fonte das cartas (uma coleção, várias no Pack Rush, ou o Cubo), depois o jeito de montar (abrir sozinho ou draftar num pod). Os decks selados em andamento ficam à mão.

Pack Rush: quem abre o pod escolhe as coleções

Selado ou Draft com boosters de coleções variadas. Quem cria escolhe quais coleções entram, e cada jogador recebe boosters sorteados entre elas: dois jogadores do mesmo pod podem abrir coleções diferentes. Com mais de uma coleção, o jogador usa qualquer Líder do jogo.

Cubo: o draft das cartas mais usadas

O Cubo é uma lista fixa de cartas, uma cópia de cada, montada a partir das cartas mais jogadas e revisada à mão. Os boosters do draft são sorteados dela, sem vaga de raridade. A página mostra a lista inteira antes de o jogador entrar num pod.
